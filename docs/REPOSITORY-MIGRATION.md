# Repository ownership

The canonical repository is https://github.com/LucasXlab/gitlore.

Clone URLs, issue links and CI badges now use the organization. GitHub repository history and pull requests were retained by transferring the original repository.

Before publishing to PyPI, verify that its Trusted Publisher uses owner `LucasXlab`, this repository name, workflow `publish.yml`, and environment `pypi`. A publisher entry configured for the previous owner must be updated on PyPI before publication. This migration does not publish or modify a package-registry release.
